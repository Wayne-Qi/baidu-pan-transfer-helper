# 百度网盘批量转存工具
基于百度网盘官方API开发的油猴脚本，一键批量转存分享内全部文件与文件夹

## ✨ 核心功能
- 批量转存分享链接内全部文件/多层文件夹
- 目标路径留空时，自动创建当日日期文件夹分类存放
- 本地记忆提取码与常用目标路径，下次打开无需重复填写
- 转存完成/任务出错自动播放提示音提醒
- 可视化实时进度条 + 完整运行日志，随时查看状态

## 📖 使用教程
1. 提前登录网页版百度网盘账号
2. 打开任意百度网盘分享页面
3. 脚本自动识别当前分享链接与提取码
4. 按需修改目标存放路径（留空自动新建日期文件夹）
5. 点击「开始转存」即可自动执行，超大文件夹会自动分批处理

## ⚠️ 注意事项
1. 必须保持网页端百度网盘登录状态
2. 单批次最多处理100个文件/文件夹，超量脚本自动拆分分批执行
3. 短时间大量转存可能触发平台限流，脚本内置自动等待重试逻辑
